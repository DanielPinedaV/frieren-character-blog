# Frieren Character Blog

Este proyecto es una página web tipo blog dedicada al personaje Frieren del anime *Sousou no Frieren*.

## Características
- Página principal con descripción del personaje
- Navegación entre secciones (biografía, logros, origen, personajes secundarios)
- Integración de imágenes y videos
- Diseño básico con HTML y CSS
- Interfaz simple y organizada

## Tecnologías utilizadas
- HTML5
- CSS3

## Objetivo
Desarrollar una página web estática aplicando conceptos de estructura HTML, estilos CSS y organización de contenido.
